# Relational Database & CLI Automation Suite (freeCodeCamp)

Sammlung aller Zertifikatsprojekte aus dem freeCodeCamp-Curriculum **Relational Database Certification**. Die Projekte demonstrieren relationale Datenmodellierung mit PostgreSQL, SQL-Abfragen und die Automatisierung über Bash-Shell-Skripte.

---

### 📂 Enthaltene Projekte

| Projekt | Stack | Kurzbeschreibung | Repository Link |
| :--- | :--- | :--- | :--- |
| **World Cup Database** | PostgreSQL, Bash | Importiert Spieldaten via Shell-Skript und führt statistische SQL-Abfragen aus. | [Repository ansehen ↗](https://github.com/janf1997-sys/freecodecamp-worldcup) |
| **Salon Appointment Scheduler** | PostgreSQL, Bash | Interaktives Buchungssystem im Terminal mit dynamischer Kunden- und Terminanlage. | [Repository ansehen ↗](https://github.com/janf1997-sys/freecodecamp_salon) |
| **Periodic Table Database** | PostgreSQL, Bash | CLI-Tool zum Abrufen von Elementdaten mit Datenbereinigung und Schemamigration. | [Repository ansehen ↗](https://github.com/janf1997-sys/freecodecamp-periodic-table) |
| **Number Guessing Game** | PostgreSQL, Bash | Terminal-Spiel mit Benutzer-Tracking und Bestenliste in der Datenbank. | [Repository ansehen ↗](https://github.com/janf1997-sys/freecodecamp-number-guess) |
| **Celestial Bodies Database** | PostgreSQL, SQL | Reines Datenbankschema mit komplexen Beziehungen (Primär-/Fremdschlüssel, Constraints). | [Repository ansehen ↗](https://github.com/janf1997-sys/freecodecamp_celestial-bodies) |

---

### 🛠️ Eingesetzte Technologien
* **Datenbank:** PostgreSQL (Tabellendesign, Foreign Keys, Joins, Aggregationen)
* **Scripting:** Bash (CLI-Tools, Schleifen, Pipe-Verarbeitung, psql-Interaktion)
* **Tools:** Git, Linux Terminal
